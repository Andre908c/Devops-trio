## ¿Qué es DevOps?

**DevOps** es una cultura y conjunto de prácticas que unen el **Desarrollo (Dev)** con las **Operaciones (Ops)**.  
Su objetivo es entregar software de forma más rápida, segura y continua.

Ciclo básico de DevOps:
1. Planear
2. Codificar
3. Construir (Build)
4. Probar (Test)
5. Liberar (Release)
6. Desplegar (Deploy)
7. Operar
8. Monitorear
